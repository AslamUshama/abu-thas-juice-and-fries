# Abu Thas Juice and Fries

Small restaurant website for Abu Thas Juice and Fries, Keelakarai — East Street, near Hairathul Jalalia School.

Customers can browse the food and drinks menus, add items to a cart, and place an order via WhatsApp to 8270247614. The shop can also be reached on 8270247614 and 8110854614.

## Run it

Open `index.html` in a browser, or serve this folder with any static web host / GitHub Pages (publish from the `main` branch, root folder).

## Notes

- Menu prices match the shop's printed menu posters.
- Orders above Rs 500 get free delivery, as shown on the site.
- Opening hours are not shown yet — they will be added when the shop confirms them.
